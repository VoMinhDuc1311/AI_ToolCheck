# AI ToolCheck Screenshots

Copy UI screenshots into this folder.

## Recommended filenames

| # | Filename | Screen |
|---|---|---|
| 1 | `login.png` | Login page |
| 2 | `dashboard.png` | Dashboard / home |
| 3 | `projects.png` | Project list |
| 4 | `project-workspace.png` | Project workspace |
| 5 | `upload-analysis.png` | Upload & source analysis |
| 6 | `api-endpoints-openapi.png` | API endpoints & OpenAPI preview |
| 7 | `test-workbench.png` | Test workbench |
| 8 | `autorun-report.png` | Batch autorun report |
| 9 | `members-settings.png` | Members & project settings |
| 10 | `ai-job-logs.png` | AI job logs |

## Rules

- Use **lowercase** filenames with no spaces.
- Do **not** use Vietnamese accents in filenames.
- Crop or blur any sensitive data (tokens, passwords, emails) before committing.
- **Never** commit API keys, JWT tokens, database passwords, AWS secrets, or personal credentials.
